Design a complete, high-fidelity, production-style responsive web application called “Sahaya”, an AI-powered government welfare and financial-assistance platform for marginalized beneficiaries, entrepreneurs, students, trainees, channel partners and officials.

IMPORTANT:
This is NOT just a chatbot website.
Sahaya is a complete government scheme discovery, eligibility, financial assistance and application guidance platform.

The existing visual reference uses:
- Dark navy government-tech aesthetic
- White content sections
- Blue primary actions
- Gold/yellow accent lines
- Rounded cards
- Clean modern typography
- Professional trustworthy government-service appearance
- Accessible UI suitable for users with low digital literacy

Preserve this visual language while making the entire product more polished, consistent, accessible and production-ready.

BRAND:
Name: Sahaya
Tagline: “Right Scheme. Right Guidance. Right Opportunity.”
Use a simple circular assistance/logo icon next to the Sahaya name.

31. IMPORTANT AI UX RULE
==================================================

The AI assistant should be context-aware across the whole website.

For example:

If the user is viewing a scheme and clicks “Ask Sahaya AI”, the assistant should know which scheme they are viewing.

If the user is on the financial calculator and asks:

“Can I afford this?”

the assistant should understand the current scheme and financial calculation context.

If the user is viewing a partner:

“Is this partner suitable for my scheme?”

the assistant should understand the selected scheme and partner context.

Therefore design the AI as a GLOBAL CONTEXT-AWARE ASSISTANT, not a disconnected chatbot.
